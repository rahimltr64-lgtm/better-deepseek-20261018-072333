# 🎓 تعلّم معي — تطبيق تعليمي للأطفال

تطبيق موبايل مبني بـ **Flutter** يعلّم الأطفال الصغار **الحروف العربية (٢٨ حرفاً)** و**الأرقام (٠ – ١٠)** بطريقة تفاعلية ممتعة، مع واجهة عربية كاملة (RTL)، وضع ليلي/فاتح، نُطق صوتي، لعبة اختبار، ونظام تذكير يومي.

---

## ✨ الميزات

- 🔤 **الحروف العربية**: ٢٨ حرفاً مع اسم الحرف وكلمة تبدأ به وصورة تعبيرية.
- 🔢 **الأرقام**: من ٠ إلى ١٠ مع الرقم العربي والهندي والنطق اللفظي وعدد الأشياء.
- 🔊 **النطق الصوتي**: عبر محرك النطق في الجهاز (flutter_tts) باللغة العربية.
- 🎯 **لعبة الاختبار**: ١٠ أسئلة عشوائية (حروف + أرقام) مع نتيجة ونجوم.
- ⭐ **نظام النجوم والتقدّم**: يُحفظ تلقائياً في الجهاز.
- 🌙 **الوضع الليلي / الفاتح / حسب النظام**.
- 🔔 **تذكير يومي** قابل للتفعيل وتحديد وقته.
- 🧭 **دعم كامل للعربية واتجاه RTL**.
- 👶 **واجهة كبيرة وبسيطة ومناسبة للأطفال**.

---

## 📋 المتطلبات

- Flutter SDK **3.19** أو أحدث (Dart 3.3+)
- Android Studio / VS Code
- جهاز Android (API 21+) أو iOS (12+)

---

## 🚀 طريقة التشغيل

### 1) إنشاء مشروع فارغ

flutter create kids_learning
cd kids_learning

### 2) نسخ ملفات المشروع

انسخ محتوى مجلد **lib/** وملف **pubspec.yaml** و**analysis_options.yaml** من هذا الأرشيف إلى مشروعك (استبدل الملفات القديمة).

### 3) تثبيت الحزم

flutter pub get

### 4) إعداد الإشعارات (مهم)

اتبع الخطوات الموجودة في الملف:

docs/android_setup.md

> ⚠️ بدون هذه الخطوة سيعمل التطبيق بالكامل **ما عدا** التذكير اليومي (سيظهر تنبيه أن الإشعارات غير متاحة).

### 5) التشغيل

flutter run

## 🎨 إضافة خط عربي جميل (اختياري)

التطبيق يعمل بخط النظام الافتراضي. لجعله أجمل:

1. حمّل خط **Cairo** أو **Tajawal** من Google Fonts.
2. ضع الملفات في `assets/fonts/`.
3. أضف في `pubspec.yaml`:

flutter:
fonts:

- family: Cairo
fonts:

- asset: assets/fonts/Cairo-Regular.ttf
- asset: assets/fonts/Cairo-Bold.ttf
weight: 700
4. في `lib/core/theme/app_theme.dart` أضف داخل `ThemeData`:

fontFamily: 'Cairo',

## 🔊 ملاحظة عن الصوت

النطق يعتمد على محرك TTS المدمج في الجهاز. إن لم يعمل الصوت:

- **Android**: الإعدادات ← اللغة والإدخال ← تحويل النص إلى كلام ← تثبيت حزمة اللغة العربية.
- **iOS**: الإعدادات ← إمكانية الوصول ← المحتوى المنطوق ← الأصوات ← العربية.
